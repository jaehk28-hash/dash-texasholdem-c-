# 성능과 승률 측정 결과

`holdem_bench`가 자동으로 만든 문서이다. 다시 만들려면 `./build/holdem_bench --out docs/bench.md`.

- 컴파일러: Apple LLVM 21.0.0 (clang-2100.1.1.101), 최적화 -O2 (CMake 기본 Release)

- 블라인드(BB)가 100이라 "평균 칩 변화/판"과 bb/100은 숫자가 같다. 블라인드를 바꾸면 달라진다.
- 합계 검산: 평균 칩 변화의 합 = -0.000000 (제로섬이므로 0이어야 한다)
