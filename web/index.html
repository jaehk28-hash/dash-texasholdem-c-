♠ 홀덤 연습

한 판의 흐름

  1. 두 사람이 블라인드(의무 베팅)를 냅니다.
  2. 각자 홀 카드 2장을 받고 첫 베팅을 합니다 (프리플랍).
  3. 공용 카드 3장(플랍), 1장(턴), 1장(리버)이 차례로 깔리고 그때마다 베팅합니다.
  4. 끝까지 남으면 카드를 공개합니다(쇼다운). 7장 중 가장 좋은 5장이 이깁니다.
  5. 나머지가 모두 폴드하면 남은 한 사람이 바로 팟을 가져갑니다.

내 차례에 할 수 있는 것

  • 폴드: 이번 판 포기
  • 체크: 낼 칩이 없을 때 그냥 넘기기
  • 콜: 앞사람이 건 만큼 맞추기
  • 벳/레이즈: 더 걸기. 입력하는 금액은 이번 라운드에 거는 총액
  • 올인: 가진 칩 전부 걸기

족보 (위가 강함)

  1. 스트레이트 플러시: 같은 무늬의 연속된 5장
  2. 포카드: 같은 숫자 4장
  3. 풀하우스: 같은 숫자 3장 + 2장
  4. 플러시: 같은 무늬 5장
  5. 스트레이트: 연속된 5장 (A-2-3-4-5 포함)
  6. 트리플: 같은 숫자 3장
  7. 투 페어
  8. 원 페어
  9. 하이 카드

알아 둘 점

  • 연습용 칩만 사용하며 실제 돈은 오가지 않습니다.
  • 칩이 0이 되면 탈락합니다.
  • 친구와 할 때는 제한 시간이 지나면 자동으로 체크 또는 폴드됩니다.
