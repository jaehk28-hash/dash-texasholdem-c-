움직임과 빛나는 효과를 끄고 가만히 보여 줘요. 이 브라우저에만 저장돼요.

내 카드 2장 + 테이블에 깔린 카드 5장 중에서, 가장 센 5장 조합을 만든 사람이 이겨요. 이길 것 같으면 칩을 더 걸고, 질 것 같으면 포기(폴드)하면 돼요.

한 판은 이렇게 흘러가요

  1. 1

    카드 받기

    나만 볼 수 있는 카드 2장을 받아요. 다른 사람에게는 보이지 않아요.

  2. 2

    첫 번째 선택

    내 카드가 괜찮은지 보고, 계속할지(콜·레이즈) 포기할지(폴드) 정해요.

  3. 3

    테이블 카드 열기

    모두가 같이 쓰는 카드가 3장 → 1장 → 1장 순서로 열려요. 열릴 때마다 한 번씩 선택해요.

    → →
  4. 4

    승부

    끝까지 남은 사람끼리 카드를 보여줘요. 가장 센 조합이 가운데 칩(팟)을 모두 가져가요. 다들 포기하면 마지막에 남은 한 명이 바로 가져가요.

버튼은 이런 뜻이에요

폴드이번 판을 포기해요. 이미 건 칩은 돌려받지 못해요.
체크아무것도 안 걸고 넘겨요. 앞에서 건 사람이 없을 때만 할 수 있어요.
콜앞 사람이 건 만큼 나도 맞춰서 걸어요.
레이즈앞 사람보다 더 많이 걸어요. 자신 있을 때 해요.
올인가진 칩을 전부 걸어요.
모르는 말이 나왔나요?
팟
가운데 모이는 칩. 이기면 다 가져가요.
블라인드
매 판 시작할 때 두 사람이 먼저 내는 최소 참가비예요. 안 내면 판이 안 굴러가서 있는 규칙이에요.
홀 카드
내가 받은 비밀 카드 2장.
프리플랍 / 플랍 / 턴 / 리버
테이블 카드가 열리기 전 / 처음 3장 / 4번째 / 5번째가 열린 단계 이름이에요.
쇼다운
마지막에 카드를 펼쳐서 승부하는 순간.
키커
같은 족보일 때 승부를 가르는 남는 카드.
딜러 버튼(D)
이번 판에서 순서의 기준이 되는 자리 표시예요. 판마다 한 칸씩 옮겨가요.

칩이 0이 되면 탈락해요.
친구와 할 때는 시간이 다 되면 연장이 먼저 쓰이고, 연장이 없으면 자동으로 체크하거나 폴드해요.
