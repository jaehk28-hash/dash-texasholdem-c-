# Coupe Holdem 사용 통계 기록

한국 시간 하루마다 한 줄씩 덧붙이는 집계 기록입니다. 날짜와 숫자만 있고, IP, 닉네임, 카드 내용은 없습니다.

```
{"date":"YYYY-MM-DD","counts":{...},"prev":"앞줄의 hash","hash":"이 줄의 hash"}
```

| 항목 | 뜻 |
|---|---|
| `visits` | 그날 온 브라우저 수 (같은 브라우저는 하루 한 번) |
| `unique_visitors` | 그날 **처음** 온 브라우저 수 (모두 더하면 누적 고유 방문자 수) |
| `solo_starts` / `room_starts` | 혼자 하기 / 친구 방 게임 시작 횟수 |
| `hands_finished` | 끝까지 진행한 판 수 |
| `src` | 유입 경로별 방문 수 (링크의 `?src=`, 정해 둔 이름 외에는 `other`, 없으면 세지 않음) |

`hash`는 그 줄에서 `,"hash":"..."` 부분을 뺀 글자의 SHA-256이고, 첫 줄의 `prev`는 `genesis`입니다.

## 검증

```bash
python3 verify.py stats-ledger.jsonl
```

## 확인할 수 있는 것과 없는 것

- 지난 줄을 고치거나 중간 줄을 지우면 검증이 실패합니다.
- 파일 전체를 새로 만들면 체인만으로는 알 수 없습니다. 이 저장소의 커밋 이력과 비교해야 합니다.
  (예전에 받아 둔 파일이 지금 파일의 앞부분과 같아야 합니다.)
- 숫자 자체가 사실인지는 보증하지 않습니다. 운영자의 서버가 센 값이며, 방문 수는 누구나 요청을 만들어 부풀릴 수 있습니다.
- 서버를 처음 켠 날의 줄은 하루 전체가 아닐 수 있습니다.
